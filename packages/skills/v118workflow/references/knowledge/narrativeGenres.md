# 十二类叙事与视听方法

本文件融合各类型的导演规划与分镜表方法。先读通用使用规则，再完整读取已确认的主类型；类型融合时再读实际采用的辅助类型。每类方法都需转成具体集、场、镜头的决定，不能只把类型名贴进提示词。

## 使用与落画布

- 用户的故事、结局、画幅、情绪基调和确认记录优先。类型是方法选择，不是禁止混合、喜剧只能开心或仙侠不能甜蜜的边界。
- 下文时长、固定机位比例、配乐覆盖和次数来自旧方法的节奏参考，均非当前模型规格。按单集长度、台词、表演、实际模型时长/镜头能力重新取舍。
- 亚秒停顿、闪切、黑屏可作为表演或后期剪辑意图；模型不支持时不提交非法时长，也不凭空发明一个后期工具。
- 连续运镜写清起幅、路线、沿途新增信息与落幅。多人交互或长镜头有一致性风险时先检查真实能力，保留剧情目的，再选择拆解、分段或后期实现。
- “少配乐”“静默”需区分无音乐、只留环境音、彻底无声。声音计划写清来源和出入点，不假定生成模型一定能输出所有声部。下文配乐方法用于已有配乐要求或待确认提案，不擅自给未要求的项目新增音乐。
- 反转允许真实局部与视点误导；幻觉、梦境、回忆有可辨标记。不能用客观画面造假、结尾临时添事实骗过观众。
- 剧本画布的“叙事方法决策”记录：主/辅类型、离场感受、段落节拍、人物关系/知识变化、代表动作、声音意图和禁用方法。它与正式剧本文字分开。
- 每集制作画布的“导演方案”承接这些决定；逐镜落实叙事目的、观众新增信息、景别构图与理由、动作/反应、运镜起落、时长依据、对白/声音和转场。按 [分镜表](../storyboardTable.md) 的七列保存可执行内容，设计理由写入其配套说明，不把这些知识维度变成另一套表格或工具字段。
- 合并只解决重复信息，不能删掉有功能的反应、对切或留白；镜头少不等于叙事好。

## 甜宠言情

**内核与节拍。** 用克制的靠近表达关系增量：初见发现 → 暗恋克制 → 靠近又退缩 → 误会/分离 → 行动解开心结 → 更深的靠近/承诺。每轮推拉要改变理解或关系，不能恢复原状后重复。冷中给暖、疏中见密；高潮可以情绪更密而剪辑仍从容。

**信息与表演。** 观众从偷看、想说又停、物件传递、手指接近、呼吸与身体距离读取情感。先写双方不知道或不敢表达什么，再写行动如何泄露。初期客套距离大，中期靠近但有物件/人群/犹豫阻隔，后期在已确认关系下消除距离。具体动作优于“很甜”。

**镜头与空间。** 同场由半身到近景、特写再到必要大特写；帘、门、窗与前景层次表示隔阂，减少遮挡表示亲密。中心构图留给正式告白等仪式，平时用三分和关系同框。缓推表示靠近/注意力收窄，缓拉表示抽离；约60%静止是可选基调。远景承载孤独或共同空间，不能一律当废镜。

**节奏、合并与转场。** 表情2–3秒、对白3–4秒、亮相3–5秒、远景4–6秒可作初排；无新信息的长停顿应缩短。定场1–2镜即可，能缓推同时引入人物就不拆三段；有持续动作与信息的长镜可参考≤12秒。场内硬切，跨场用一个环境/独处片段缓冲，大段情绪转换再用叠化或淡入淡出。

**声音。** 初见、对视和转身可撤掉音乐只留环境音；按情绪段落确定一首基调，不逐场换曲。日常轻器乐，暗涌单一乐器低声，和解温暖渐入，暧昧用轻打击或拨弦表现心跳。旧配乐覆盖≤60%仅供留白规划，每场选1–2个可辨环境声。

**禁忌与输出。** 不靠连续快切或满配乐强推甜感，不滥用眼唇大特写。旧版把拥抱/接吻改成局部是生成限制下的选项，当前不得未经同意删改此类剧情。写入每场“关系从何状态到何状态、距离如何变化、关键反应何时被观众看见”，再由分镜落实完整动作或可行拆镜。

## 悬疑推理

**内核与节拍。** 正常表面出现裂缝 → 发现异常 → 调查 → 看似成立的解释 → 新证据推翻 → 回溯拼图。真相可分3–5层，释放一条有价值的信息后留下新的具体疑问；收紧—短松—更紧，不以一直不回答代替悬念。开篇尽早给可追问的异常，旧30秒可作短篇参考。

**信息设计。** 每段列出事实、观众知道/误以为知道的事、角色所知与被遮挡信息。误导线索须有日常合理解释；重要证据至少“自然出现”与“揭示意义”两次。可用倒叙、插叙和并行视点，但每次跳时空有视觉/字幕等清晰标记。核心反转用道具状态、空间全貌或视点重释呈现，小信息可用对白。

**表演与线索。** 可疑行为有日常外衣，如看表、擦手、折信；允许多种解释，不能每次配一个“坏人脸”。微表情和手指停顿是线索，不是一套必然测谎规律。关键动作一镜聚焦一到两项，避免多项杂动作淹没证据；未说完的话配有意义的沉默。

**镜头与构图。** 中景展示够多但藏关键局部；特写用于有理由的证据注意；全景揭示原来被遮住的全貌。线索可放边缘、前景和深焦背景，但必须真实可见。遮挡缓推是窥视，横移是搜索，缓拉是揭示，突然停镜是发现。荷兰角留给失序节点，中心或环绕用于审视/对峙，不把每镜都拍成异常。

**节奏与揭示。** 日常2–4秒；关键发现比日常多1–2秒；反转前4–5秒蓄压；揭示可1–1.5秒冲击或5–6秒缓揭。先角色反应后所见让观众等待，先观众看到后角色反应制造焦虑；选择后写明顺序。反转后留1–2镜消化。调查不盲目碎切，追逐才适合加速；闪回可用匹配动作/物件切入。

**声音。** 日常配乐混入微弱不协调；调查用低声节奏或倒计时环境音；反转前抽音乐甚至静默。未知声源可误导，最终需有合理声源解释。关键场景写一个反常声音及其什么时候恢复/揭晓；旁白仅补必要推理，不代替证据。

**禁忌与输出。** 不用特写、超长停留或提示音给伏笔画箭头；不破坏道具位置连续性；不靠新增事实反转。创作决策节点保存“线索—初次出现—误读—兑现”，分镜表保存精确道具状态与揭示顺序；成片画面不贴“这是伏笔”的解释标签。

## 热血少年与动作

**内核与节拍。** 先建立为什么而战，再让危机和真正失败检验信念；每轮蓄力 → 临界 → 爆发 → 代价/喘息。低谷需有损失与反思，成长通过从躲闪到迎击、从倒下到再次站起来看见。高潮可叠主角站起、伙伴赶到、信念兑现三层，过度叠加会抵消力量。

**信息与表演。** 战斗先给双方目标、能力差距与限制，让翻盘有可追溯的准备。代价用伤口、颤抖、疲惫和被破坏环境呈现；不是角色喊“我变强了”。伙伴用交换眼神、交付后背和主动承担风险建立信任；救援可按主角绝望 → 声音/光影入侵 → 揭示伙伴三拍。

**镜头与攻防。** 低谷俯拍，站起或兑现仰拍；从俯到仰可在同场映射逆转。全景交代站位和攻防方向，中近景看动作，特写聚焦临界眼神/拳头；中心构图和环绕留给少数英雄时刻。攻—防—退—再攻有来回，最后一击按蓄力、出招、命中、结果四拍组织，不能全是命中特写。

**节奏。** 蓄力4–5秒、必要升格约6–8秒；冲击1–1.5秒；日常2–4秒。慢长蓄力接快短爆发形成反差；平时保留日常温情/幽默喘息。快推传力量，跟拍传并肩与追击，横移传速度；可读性优先于晃动。连续退避再冲锋有充分空间信息时可合成长镜。

**声音与台词。** 危机先撤音乐再给低声压力；爆发前3–5秒可只留呼吸/心跳，主题曲在临界动作切入。鼓点从稀到密映射蓄力，拳风、脚步、碎石等声层承载力度。信念宣言精选，站起可沉默；呐喊和环绕都留给少数真正兑现，不每招重复。

**转场与禁忌。** 战斗内硬切，回忆短插只补当下信念，段落间环境镜头让情绪降下来。闪白/短黑屏是剪辑意图，按能力处理。禁止无理由升级、永远无代价获胜、只拍乱战不交代空间。写入每轮“差距—准备—失败/代价—选择—兑现”和分镜力量方向。

## 喜剧搞笑

**内核与节拍。** 角色认真追求一个目标，性格碰撞和预期违背产生喜感。铺垫建立正常逻辑 → 小意外 → 补救更糟 → 误会连锁 → 失控 → 真情/回归 → 最后一记余包袱。荒诞必须有内部因果，角色越认真越有效，不能自己先替观众笑。

**包袱与信息。** 三遍法则：第一次建模式，第二次强化，第三次改变；重复时第三遍必须有新差异。误会链写明A误解了什么、B如何误解其反应、第三人知道多少。尴尬可从自己出错、被人看到、补救失败到集体失控升级；不要把无关段子拼起来。

**表演与调度。** 写具象反差，如郑重其事地完成荒唐任务；为笑点保留旁观者。包袱后接反应，群戏可依次有惊呆、偷笑、假装没看见等不同反应；多人同时失控用全景让观众自行发现。真情段落露出角色脆弱或善意，别急着消解一切情感。

**镜头。** 全景给观众角色不知道的背景，中景承载性格互动，近景捕捉反应，特写短暂放大错误细节。约60%固定旁观可作基础；急推放大石化，甩镜揭示荒谬，缓推发现细节，失控时才跟拍。能一镜看到连锁失控就不拆碎；三遍相同构图第三次改变，形式也参与包袱。

**节奏与剪辑。** 铺垫3–4秒、包袱1.5–2秒、反应2–3秒，笑点后可留1–2秒给消化。吐槽紧接上句，包袱前微停顿；旧“笑点间隔不超过60秒”仅用于检查喜感长时间缺席，不能破坏必要真情段。连锁失误可逐次缩短硬切；“绝不这样做”直接切到正在做、计划与灾难交替剪辑都能形成视觉包袱。

**声音。** 荒谬画面配正经音乐或继续正常环境音；极荒谬动作前突然全停形成反差。环境声可充当包袱：不合时宜的手机响、肚子叫；重复声音建立节拍，第三次打破。真情时撤配乐，避免每个包袱都加小丑音效和罐头笑声。

**禁忌与输出。** 铺垫未建立就抖包袱、包袱后没有反应、快推进剪断笑声、花哨运镜抢角色戏都应检查。写入“预期—打破点—反应者—消化空间—三遍变化”，由分镜落实信息差和精确节拍。

## 科幻末世

**内核与节拍。** 生存危机 → 寻找资源/庇护 → 信任试探 → 短暂微光 → 更大代价 → 道德选择 → 带伤继续。每次行动有资源成本；信任从试探、合作到更高赌注的背叛或坚守。结尾可以仅获得继续走的可能，不强制世界恢复正常。

**信息释放。** 用文明残物代替设定演讲：家庭照片、废校车、失效设备和寻人启事说明曾经的生活。近期末日保留刚离开的痕迹，中期锈蚀与杂草，远期坍塌与植被覆盖；环境衰败程度保持时间一致。每次到达地点同时给资源、威胁、出口信息，环境也是敌人。

**行为与抉择。** 搜索用扫描空间 → 靠近目标 → 检查物品 → 有/无结果；争夺资源同时给对方恐惧和自己犹豫，避免只拍抢夺。道德抉择三拍：处境全景、人物挣扎、实际选择。牺牲用最后对视、走向危险、留下者反应；微小善意贵在代价清楚。

**镜头。** 废墟远景与微小人影表现文明尺度；狭窄通道、前景残骸和倾斜空间表现压力；特写看龟裂嘴唇、脏手、最后一口水。设备中景给全貌再特写损坏细节，遗物大特写慎用。微手持随危险程度增减，缓移搜索，快推危机，缓拉从细节揭开荒芜；清晰地理优先于混乱感。

**节奏与转场。** 废墟5–6秒、生存行动2–4秒、危机1.5–2秒、道德抉择4–5秒；探索长镜可参考8–10秒并持续新增空间信息。荒原行走是段落呼吸，可几镜无对白配乐，但仍给迁移/状态变化。场内硬切，跨场可用废墟片段、信号干扰或同地点衰变对比；回忆文明用更明亮质感与当下区分。

**声音。** 缺失本应存在的城市/机器声音表现消亡；风、金属、漏气、无信号广播和间歇报警构成稀疏音景。决定是否抛弃同伴时撤配乐，只留呼吸环境声；希望微光才让单一温暖器乐进入。旧配乐≤30%提示克制，不要求机械计时。

**禁忌与输出。** 不让资源无限补充、伤势无故消失，不用角色长谈解释整个灾变，也不用无意义废墟空镜凑氛围。写入每段“资源余量/成本—威胁—信任变化—道德代价—微光”和环境时间状态。

## 都市职场

**内核与节拍。** 用利益链推动行为：升职、保位、预算、专业信誉和安全感。占优 → 对手借事件反击 → 被动 → 找突破 → 小胜/小败 → 新代价；关键转折落实到邮件、泄密、资源决定等具体事件。中间有阶段结果，结尾保留关系或原则的代价，避免无成本逆袭。

**信息与表演。** 写谁掌握什么、抄送给谁、公开话与真实意图差在哪里。观众先知背叛会焦虑，跟主角同知会共情，按场选择。会议微笑、按笔帽、签字犹豫、洗手间深呼吸体现压力；独处与通勤是卸下面具和切换角色的叙事，不只是过场。

**空间与镜头。** 主位、门边、独立办公室/开放工位、玻璃与隔板体现权力。中景保留正式社交距离，近景意味着信任或压迫，特写揭露微表情。上级靠近/下属退让、同盟并肩/对手隔桌都须由剧情支持。会议从全景到对抗近景，关键潜台词接听者反应；群体发言不必逐人切镜。

**运镜与节奏。** 约65%固定可作冷静观察基调，走动用极微手持；缓推审视、缓拉孤立、横移呈群体关系。对白2–4秒，沉默博弈3–4秒，日常碎片1.5–2秒，独处4–5秒；镜头是否延长由信息变化判断。能横移兼顾说话与反应可合镜，不能因此抹掉关键攻防。

**声音与转场。** 键盘、空调、翻纸、咖啡机、电梯、消息震动给空间身份；关键会议撤配乐，让沉默施压。音乐多为低声底噪或克制器乐，旧覆盖≤40%是参考。日常用闹钟—通勤—打卡—加班蒙太奇，办公室硬切安静的家表现割裂，手机新消息可触发下段；大跨度用明确时间线索。

**台词与禁忌。** 台词可礼貌地拒绝/试探，但听者反应须能帮助理解；重要问话后的沉默标明施压者。少旁白解释心理，避免行业细节失真、把所有斗争写成吵架、把职场拍成励志广告。写入“利益动机—信息权限—权力位置—表里意图—代价”，让每场变化可追溯。

## 古风仙侠

**内核与节拍。** 天道/责任与个人情感相冲突；宿命是选择的起点。预言或旧因 → 修行与羁绊 → 心劫 → 身劫 → 天劫/终极选择 → 新领悟。每次领悟要改变行动和代价，不能只升级战力。前世、今生、来世可形成因果层，但必须与已确认原作相符。

**信息与表演。** 预言、天象、信物和旧记忆分次出现，观众等待它们怎样兑现；师徒赠物、道侣默契、宿敌对视比长篇解释更有力。角色面对宿命选择接受或抗争，行为体现从执念到放下、从求仙到问心。诗化意象要落成可见物理变化，不能只有抽象词。

**天地与镜头。** 山脚到山巅的空间可映射境界；平静、风雨、雷动、云开分别与情绪变化呼应，但不擅自新增法则。大量天地留白中放微小人物，云雾遮蔽、前中远景层叠增加空间；中心构图留给仪式。远景讲孤独和格局，特写讲信物/灵力，大特写只在见微知著时使用。

**运镜与战斗。** 静止或极缓约70%为参考；缓摇如展卷、缓推入境、缓拉出世、升降对应飞升/入世，飞行跟拍稳而从容。法术写起手—蓄力—释放的完整意图；一招一镜而非碎切，终局可蓄力—对视—出手—停顿—结果。天象升级随具体招式标明，不能特效遮住因果。

**节奏与转场。** 意境5–6秒、互动3–4秒、一招3–5秒、悟道可6–8秒且有风云水光等自然动态。修行沉默可以多镜，只要人物/时间/境界在变化。云雾覆盖散开、四季流转、水面倒影、梦境叠化分别负责空间、时间、回忆；同场仍可干净硬切。

**声音与台词。** 松涛、瀑布、风铃、远钟是主要音景；古琴箫笛埙一句一停，战斗鼓锣钟，关键一声剑鸣可比满配乐更有力。吟唱留给重大仪式。对白言简意深，诗化旁白配山水/远景；采用融合类型时不机械禁止现代音色。

**禁忌与输出。** 不把仙侠一律改成快节奏打怪，不因通用“少意象”删掉本类型有效空镜，不用炫技运镜和满屏法术代替抉择。写入“命运伏笔—人物执念—每次劫的代价—悟道行动—信物/天象兑现”和每段天地对应关系。

## 历史史诗

**内核与节拍。** 用时代洪流中个体的选择照见忠义、生死、个人与集体。宏观局势与微观人物交织，积蓄 → 爆发 → 沉淀形成大波浪；群像各有情感弧，在关键历史节点交汇。规划每个人的“最后一次”回望、举杯或并肩，使仪式来自不可逆意义。

**信息与人物。** 不靠长旁白重述背景；命令的后果、秩序崩塌、平民生活和人物取舍说明时代。白发、新草、孩子长大、新人坐旧位表达时间跨度。大抉择可沉默完成，动作要说明选择，不能只有庄重台词。

**空间与构图。** 朝堂对称表示秩序，站跪/高低/前后表示权力，势均力敌者平视；群像有贯穿的焦点人物。远景给时代尺度后，人物特写作为人性锚点；纵深位置与空旷中的小人影讲孤独。定场应同时说明时代处境，避免只有地名字幕。

**运镜与时长。** 静止或极缓约70%可作基调；俯瞰平移像时代画卷，缓推聚焦抉择，缓拉从个体揭开全局，重大仪式可不动见证。远景5–7秒、对峙4–5秒、仪式动作3–5秒、特写3–4秒；战斗靠空间与景别变化，不一概压成碎片。行军、迁徙、朝堂可连续涵盖，长镜参考≤15秒并持续更新信息。

**声音与转场。** 低音器乐与鼓承载重量，战歌/吟唱承载群体，重大决定和余震可只留环境声。战场分近处呼吸兵刃、中景人声、远处号角马蹄；不是一团噪音。空镜做情绪缓冲，意象叠化表达年代，渐黑/渐亮用于大段历史翻页，场内硬切。

**禁忌与输出。** 仪式每个动作要有意义，不用规模代替重量；不以所有人慷慨演说替代抉择，不把群像强行缩成单线爽剧。写入“历史事件—受影响个体—选择—时代后果—个人代价”，导演方案再落实宏微转换、权力站位与仪式动作。

## 家庭温情

**内核与节拍。** 日常循环下有逐渐老去、即将离家或关系疏远的暗线；日常 → 笨拙关心 → 代际分歧 → 分离威胁 → 行动和解 → 回归/传承。高潮可以是一顿重回同桌的饭，不必争吵爆发。“最后一次”的日常与孩子重复父母动作带出时间重量。

**信息与表演。** 爱由备伞、添饭、留灯、行李塞食物等习惯动作透露；家常话表面简单，行动补全情感。观众可看到当事人没看到的关心。两代人选择对照，既有传承又有差异；不要把重复本身删掉，比较重复中关系发生的改变。

**物件与空间。** 食物传递关心、旧物传递时间、钥匙和门传递归属。餐桌满座、空位、只剩两人就是关系变化；厨房、客厅、孩子房间各有功能。中景/全景保家人同框，前后景给默默注视，门窗框给保护与离开；特写用于颤抖的手、压下的笑、热汤等情感证据。

**运镜、时长与合并。** 以静止和安稳缓移为主，旧约70%供参考；缓推发现留饭，缓拉目送，跟移端菜至餐桌可完整呈生活流。日常3–4秒、沉默4–5秒、细节2–3秒、目送5–6秒。餐桌戏不必逐人碎切；归家或端菜长镜参考≤12秒，速度跟随生活而不是炫技。

**声音与对白。** 炒菜、水壶、拖鞋、电视模糊声构成家的节律，关键亲情撤音乐保生活声；“吃了吗”“到了打电话”配动作足够。旧配乐≤40%提醒节制，和解可温暖渐入，代际回响再给完整主题。钥匙声与进门招呼可重复成为安心锚点。

**转场、禁忌与输出。** 早中晚、季节循环与生活细节负责转场，大段落可缓叠化，同场硬切。避免苦情堆砌、强迫催泪、台词总结爱的伟大、快剪打断习惯动作。写入“重复日常—本次差异—未说出的关心—物件/空位变化—和解行动”，保留有信息的从容与沉默。

## 青春成长

**内核与节拍。** 围绕第一次心动、失败、告别或挺身而出的笨拙，成长走“以为懂了 → 被事实打破 → 作出新选择”。日常相聚与共同经历累积，再走向分离和回望；疼痛有具体代价，甜蜜与遗憾共享“时间不能重来”的底色。

**结构与信息。** 允许情绪线串联碎片，也允许现在回望过去的双线；每个关键变化绑定具体“那一天”的天气、活动或物件。用老师、朋友、家长等旁观者发现主角变化。教室/操场建立归属，回家路承载心事，秘密基地承载承诺；同地从并肩到独行说明关系。

**表演与关系。** 想说又停、碰手缩回、故意绕路又偷看体现笨拙；群戏每人有不同小动作，叠话不必句句整齐。身体距离从隔座、并肩、各站一边到再次靠近，可记录关系状态。真正成长可能是不再争辩或不再追赶，让沉默与行动说话。

**镜头与节奏。** 群像全/中景给“在一起”，前后景给单向注视，对称并排给平等陪伴；远景可自由或孤独，须写理由。动静交替，跟拍奔跑有生命力，缓推注意到变化，缓拉告别，成长时停镜。日常碎片2–3秒、情感4–5秒、顿悟3–4秒、季节远景4–6秒；旧静止50/跟拍缓推30/微手持20只是可选比例。

**合并与转场。** 日常碎切本身有功能，不强行合并；告白、争吵、和解尽量保持连续发展；群戏一镜保整体。奔跑/穿越校园长镜参考≤12秒并有心情变化。时间用同角度黑板、座位、树叶的变化对比；重大情绪转折给空镜缓冲，日常用快切蒙太奇。

**声音。** 铃、球鞋摩擦、翻书、哨声、自行车构成记忆锚点；主题旋律不同编排勾起旧情绪。群体欢闹到单一声部可以表现告别，成长节点撤配乐。笑转哭、哭转笑的人声足够时不强加音乐。

**禁忌与输出。** 不写完美成熟的少年、不把成长变成功利胜负、不用一场说教替代经历。写入“第一次—错误理解—付出代价—新行动—那一天/记忆空间”，再让镜头的同地变化与声音回响对应起来。

## 恐怖灵异

**内核与节拍。** 正常安全 → 微妙异常 → 异常侵蚀 → 假性安全 → 最坏预感确认 → 日常中残留异常。威胁从远处/外面进入熟悉空间，再到身边无处逃；高潮既可是危险出现，也可是“原来一直如此”的理解改变。

**信息控制。** 每段写观众与角色各知道多少；怪物全貌或威胁来源延迟、分次揭示，让了解更多反而更怕。熟悉空间多出的椅子、人影、照片细节比凭空血腥有效。真假难辨时标记体验视点，结局必须能解释先前异常，不无依据篡改现实。

**表演与镜头。** 先写僵住、压住呼吸、手指攥紧、缓退等身体反应，不每次尖叫狂奔。特写限制周边视野，远景暴露角色未知危险，门缝/遮挡/纵深焦外与偏侧留白保留潜在威胁。定场就可埋一处不对劲；不急于给完整恐惧源，反应常更有效。

**运镜与时长。** 静止约70%是参考，极缓推逼近，缓拉揭示身后，运动突然停下制造注意，微幅呼吸感可暗示窥视。寂静3–4秒、反应3–4秒、氛围远景5–7秒可供初排；惊吓约1–1.5秒，与等待形成差异。探索走廊到房间尽量维持连续不安，长镜参考≤15秒且有信息渐变。

**声音。** 正常环境声 → 稀薄 → 安静 → 声源不明的异常；假性安全恢复日常声，结尾同一异常音重现。低声不协和、低频音色可作氛围设计，不把固定次声频率当作必然恐惧效果。跳吓少用，先有静默积累；声音先于下个场景可形成入侵感。

**转场、禁忌与输出。** 悬压段不随便插舒缓空镜，假性安全另有明确目的；硬切、短黑屏或声音先行按节奏取用。不可用持续巨响、连续跳吓、过早全貌、过多解释对白消耗恐惧。写入“安全区—异常证据—双方所知—假安全—确认—余韵异常”，逐镜明确藏什么、露什么。

## 心理博弈

**内核与节拍。** 表面和平 → 试探 → 裂缝 → 察觉 → 反将一军 → 更深伪装 → 揭底。每回合短暂释放后赌注升级，角色动机各自可理解；观众不必简单站队。认知层可以有“我知道你知道”，但必须让证据足以支持。

**信息与视点。** 每段做三方表：A所知/假装不知、B所知/假装不知、观众所知；选择上帝视点看陷阱或跟随视点共同被骗。切换视角必须产生认知更新，反转前用多个独立细节预埋，不拿层数越多当越好。

**对白与微动作。** 每句标表面话、真实目的和动作：问话进攻，回避防守，反问反击，沉默施压。标记沉默由谁制造、谁承受；喝水、指尖停顿、眼神偏移可被误读，不能把它们当固定测谎器。多义回答要结合上下文成立，避免故作神秘的空话。

**空间与景别。** 对称双人中景表示平衡，第三人三角构图引入变量，偏侧或被困角落表示不利；起身、走窗边、背对让空间权力变化。中景看肢体，近景/特写读破绽，远景看格局，大特写只投关键线索。正反打每次切换是一轮攻防，不为减少镜头强行合成双人镜。

**运镜与节奏。** 核心对峙静止，旧约60%–65%是参考；极缓推施压、缓拉揭全貌、微偏移示天平倾斜，揭底才可骤变景别。对白3–5秒、对峙沉默4–6秒、微表情2–3秒、反转1–2秒；实际停顿以台词和计算过程为准。空间走位推动心理变化时可长镜参考≤12秒。

**声音与转场。** 和平段轻衬或无音乐，试探渐入低声不协和，摊牌突然抽掉音乐，僵持只留环境与呼吸。温暖音色可配合角色假象，但最终有依据；心跳不能每次等同说谎。回合或视点转换用干净硬切，短闪回补当下识破的线索，场景切换保张力，必要时给角色独处思考。

**禁忌与输出。** 每镜须有信息层，不用无功能氛围和普遍快切打断读表情；不靠最后突然出现的证据证明某人早已全知。写入“回合目标—双方底牌—观众位置—台词双层含义—微动作—沉默归属—优势如何转移”，分镜按完整回合组织。
