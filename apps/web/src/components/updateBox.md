### 新增

- 首页和 Agent 对话支持选择、拖入或粘贴附件，新增 Word、Excel、PowerPoint、PDF、EPUB 等文档及代码文件支持，方便直接使用已有创作资料。
- Agent 可读取工作区和全局素材库中的文档，将内容解析为可阅读文本；扫描版 PDF 需先进行 OCR。文本节点也可引用文档作为生成参考。
- 新增「v1.1.8 分集制作流程」技能，支持从小说或剧本逐步完成分集剧本、资产、分镜和视频制作，按阶段确认结果，并在剧本、资产和分集画布中整理成果。
- 节点菜单支持自定义，可调整顺序、创建多级分组、设置节点别名、隐藏菜单项，并恢复默认布局。
- 图片、视频和音频生成节点支持显示预估价格与计费说明，画布可查看账户余额；需供应商提供对应能力，实际费用以结算为准。
- 文件树支持展示画布内的节点分组层级，并可通过右键菜单聚焦画布中的对应节点。

### 优化

- 优化 Agent 多图对话，自动缩放发送图片，请求过大时减少本次发送的历史图片，原图保留并可按需重读，减少请求超限导致的中断。
- 画布目录改为按需加载，展开文件夹时读取其中内容；搜索和 Agent 跨画布引用仍可查询完整画布列表。
- 完善画布鼠标与快捷键配置，滚轮缩放、画布平移可设置为无需按键，并支持自定义框选和追加选择按键。
- 调整工作区底部工具布局，集中添加节点、移动与抓手切换及帮助入口；空白画布提供图片、视频和音频生成入口，便于开始创作。
- 修改供应商配置或安装供应商后，图片、视频和音频生成节点自动刷新模型列表，减少手动切换操作。
- 媒体生成结束后自动刷新支持查询的账户余额，并同步到画布和设置界面。
- AI 错误解释支持自行选择文本模型，保留原始错误，并单独显示解释服务的失败信息，便于更换模型后重试。
- 完善联网搜索失败与超时提示，补充具体原因和切换搜索服务的设置路径。
- Windows 正常启动失败时可选择兼容方式启动，并查看具体错误信息。
- Windows 安装时加强 WebView2 运行环境检测，异常时提供组件修复入口和诊断信息。
- Android 客户端在系统 WebView 能力不足时自动启用应用内置的备用内核，无需额外联网下载内核。

### 修复

- 修复 Windows 更新助手启动失败后需要重新下载更新包的问题，支持保留已验证的更新包直接重试，并完善失败诊断。
- 修复隐藏画布连线后，部分节点连接点测量异常导致连线位置偏移的问题。
- 修复重复框选节点时选择状态残留的问题，完善追加选择操作。
- 修复提示词中的参考图片缩略图临时地址被写入保存内容的问题。
- 修复 Agent 创建目录时可能因自身会话文件被误判占用而失败的问题。
