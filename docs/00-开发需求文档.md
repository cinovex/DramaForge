---

## 一、项目定位

一个可插拔多模型的 AI 短剧/漫剧创作平台（"AI 漫剧画笔"）。用户上传剧本，平台自动完成
「大纲拆解 → 资产生成 → 分镜拆解 → 逐镜头视频生成 → 成片导出」全流程。

核心特色：每个创作环节的 AI 模型可在设置里自由配置、切换（像换画笔一样）。

---

## 二、技术栈

| 层 | 技术 |
|---|------|
| 前端 | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| 后端 | Python FastAPI + SQLAlchemy |
| 数据库 | SQLite（轻量项目管理，零配置起步） |
| 异步任务 | 后端 asyncio 后台任务（起步不引入 Celery/Redis） |
| 文件存储 | 本地文件系统 D:\DramaForge\storage |
| API 对接 | GPT 官方 api.openai.com · Agnes 国内站 api.agnes-ai.cn |

---

## 三、API 分工

| 环节 | 模型 | 接口 |
|------|------|------|
| 剧本分析 / 大纲 / 分镜 | GPT (gpt-4o) | POST /v1/chat/completions |
| 图片生成 | GPT (gpt-image-1) | POST /v1/images/generations + /edits |
| 视频生成 | Agnes Video 2.5 | POST /v1/videos 轮询 GET /agnesapi |

---

## 四、功能模块

```
模块0  设置中心      —— 配置各环节 API key / base_url / model（可插拔核心）
模块1  剧本创作入口  —— 上传 txt/docx 或粘贴 / AI 生成剧本
模块2  剧本大纲      —— 风格/概要/分集元数据展示 + 确认
模块3  资产库        —— 角色/场景/道具列表 + 生成 + 重新生成
模块4  分集视频      —— 分镜列表 + 关键帧 + prompt + 生成视频 + 历史
模块5  成片导出      —— 片段拼接 + 下载 MP4
```

---

## 五、数据模型

```
Project(项目) ─┬─ Outline(大纲: 标题/风格/画幅/概要)
               ├─ Character[](角色: 名/描述/形象图)
               ├─ Scene[](场景)
               ├─ Prop[](道具)
               └─ Episode[](分集) ─── Shot[](分镜: 标题/时长/prompt/关键帧/视频)

Setting(全局配置) ── 各环节的 provider/api_key/base_url/model
```

## 六、分步实施计划（开发一步 → 测试 → 确认 → 下一步）

### Step 1：项目骨架 + 可运行的前后端
- 建目录结构、初始化 Next.js 和 FastAPI
- 后端跑通 /health，前端跑通首页
- SQLite 建库、建表
- ✅ 测试：前端 localhost:3000、后端 localhost:8000/docs 都能打开

### Step 2：设置中心（可插拔核心）
- 设置页 UI：3 个环节各填 provider/key/base_url/model
- 后端 Setting 的增删改查 + 加密存储 key
- "测试连接"按钮验证各 API 可用
- ✅ 测试：填入真实 key，点测试连接，GPT 和 Agnes 都返回成功

### Step 3：剧本创作入口 + 项目管理（模块1）
- 项目列表页 + 新建项目
- 上传 txt/docx（解析文本）/ 粘贴 / AI 生成剧本
- ✅ 测试：上传一个 txt 剧本，能看到文本入库

### Step 4：GPT 剧本解析 → 大纲（模块2）
- 后端调 GPT 把剧本解析成结构化 JSON（标题/风格/画幅/分集/角色/场景/道具/分镜）
- 大纲页展示元数据，可编辑确认
- ✅ 测试：真实剧本解析出完整大纲 JSON

### Step 5：资产库 + GPT 图片生成（模块3）
- 角色/场景/道具三个 tab 列表
- 调 GPT Image 生成形象图、支持"重新生成"
- ✅ 测试：角色列表每个都能生成出图并显示

### Step 6：分镜 + 关键帧 + Agnes 视频生成（模块4，核心）
- 分镜列表 + 单镜头详情 + prompt 编辑
- GPT 生成关键帧 → 关键帧作参考图喂给 Agnes Video
- 单镜头生成 + 后台轮询 + 进度显示 + 历史记录
- ✅ 测试：选一个分镜点生成，几分钟后出现可播放视频

### Step 7：批量生成 + 成片导出（模块5）
- 整集批量生成（并发控制）
- 片段按顺序拼接导出 MP4（ffmpeg）
- ✅ 测试：一键生成整集 → 导出一个完整 MP4

### Step 8：角色一致性优化 + 自然语言修改 + 收尾
- 角色图参考链路优化（保证跨镜头一致）
- 用自然语言指令局部重做某个镜头
- 整体联调、异常处理、文档
- ✅ 测试：完整走一遍「剧本→成片」，角色不崩
