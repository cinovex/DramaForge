# DramaForge 制作流程与跨账号续做基准

版本：2026-10-25。性质：用户已确认方向的需求与验收基准，不代表以下功能已全部实现。

## 1. 最终目标

我们的网站负责整个短剧项目、制作任务、进度和成果。Pippit、国内即梦、国际版 Dreamina 及其他模型 API 是可更换的执行来源。

用户在我们的网站导入剧本或视频，完成分析、资产制作、分镜编辑、视频生成和成片管理。生成时在我们的网站选择实际可用的平台、账号或 API、模型及其参数，不以跳转第三方官网代替接入。

核心不只是“所有账号使用同一套参考图”，而是：**同一个项目分项保存进度和成果，换账号或 API 后继续未完成部分；已保存资产不依赖原账号持续有效。**

### 必须通过的典型场景

假设账号 A 有 2000 积分，先完成一部分剧本分析、角色、场景、道具、分镜或媒体生成：

1. 每个已完成单元立即进入我们的项目，能看到完成内容和剩余数量。
2. A 积分不足或用户主动暂停时，保留已完成结果，未完成项标出原因。
3. 用户选择账号 B 或另一 API，先校验其能力和参数，再只执行未完成项；已经成功保存的任务不重复收费生成。
4. 两个来源完成的内容共同呈现在我们的项目、资产库与画布中，无须手工拼接两个第三方项目。
5. A、B 退出登录甚至注销后，本地已下载且校验通过的图片、视频、文本设定和提示词仍可打开、编辑、导出和作为后续参考使用。平台仍须允许该素材被下载和使用。

账号之间不合并积分，不假设能把平台内部运行到一半的单次请求迁移给另一账号。接续点是我们已经持久保存的任务边界。对于尚未返回结果的请求，必须显示等待或结果未知，不能宣称已接管它的内部进度。

## 2. 完整制作流程

### 2.1 导入与项目设置

- 支持上传剧本、粘贴文本以及视频重制入口。原始文件先保存到项目，再提交分析。
- 在提交区直接提供风格、比例；视频重制同时提供目标地区。已选值显示在按钮或标签上，重新打开项目仍能看到。
- 提交后进入本地项目。原始内容、选择项、分析进度、资产及后续任务都属于同一项目。
- 文件格式、数量、时长、大小限制依据实际解析器和所选平台能力显示；截图中的限制仅为参考，不直接写成所有平台通用限制。

### 2.2 分析与逐步出现的结果

- 读取与拆分剧本后，分项处理故事/分集、角色、场景、道具及分镜；长剧本以可恢复的单元分析，不依赖一次完整大 JSON 返回才能显示全部结果。
- 显示真实阶段与数量，例如“正在读取剧本”“角色 5/13 已完成”“分镜 18/60 已完成”。总数未确定时显示已完成数量与进行中状态，不编造百分比或预计总数。
- 每个完成单元保存后即显示为可查看内容；正在处理和失败项单独标识。
- 跨分集的角色、场景和道具保持本地稳定 ID，使用可追踪的合并与修订机制，不能因换来源重新建出两套同名角色。
- 分析得到文字设定或提示词不代表图片、视频已经生成；界面分别表示这些状态。

### 2.3 资产制作

- 角色、场景、道具、素材分类及数量在我们的项目内显示。
- 支持单项与多选生成、查看/编辑设定和提示词、上传已有参考、查看状态及失败原因。
- 每项图片完成即下载、验证、登记、显示，随后可用作其他任务的参考。
- 已有资产的重新生成必须是明确操作，产生新版本并保留旧成果；切换来源和继续剩余任务不得隐式重做已完成资产。

### 2.4 剧集与片段编辑

- 剧集列表显示每集标题、角色/场景数量、分镜和视频状态，支持按集进入编辑。
- 编辑页采用用户提供的三栏参考结构：左侧制作资产库，中间分镜与提示词编辑，右侧视频预览，底部片段切换。
- 顶部显示当前集、保存状态、视频生成来源/模型、清晰度与比例；已选配置始终可见。
- 片段支持单独编辑与生成。片段完成即保存，批量任务允许部分完成、暂停和继续。
- 图片生成和视频生成分别选择模型，不能把文本分析模型误当作视频模型。

## 3. 选择器必须出现在我们的网站中

用户截图参考的是交互与布局，不是可直接调用的接口目录。以下控件必须具备实际行为和持久化，不能只做外观。

| 选择项 | 位置与交互 | 数据与生效规则 |
| --- | --- | --- |
| 风格 | 导入区和项目设置；紧凑按钮弹出搜索、分类、缩略图网格，支持“无”及自定义 | 分类可参考真人实拍、2D、3D；每个预设保存本地 ID、版本、风格说明、提示词/参考素材。第三方未开放风格目录时使用明确标注的本地预设，不伪装成官方同款 |
| 目标地区 | 视频重制提交区，弹出文字菜单并显示当前选择 | 截图中的中国、日本、韩国、美国、印度尼西亚、巴西、南非作为候选参考；实际作为创作内容设定保存，不等同于 API 路由地区、账号区域或网络出口 |
| 比例 | 导入区、项目设置和生成工具栏；图标配数字 | 候选可参考 21:9、16:9、4:3、1:1、3:4、9:16；生成时只能选择当前模型支持的值 |
| 平台和账号/API | 最终提交生成前可选择，并能查看当前使用项 | 来源必须绑定具体凭据引用和账号别名；不能只改一个模型文字标签而仍使用上次账号 |
| 模型 | 资产生成与片段编辑工具栏，紧凑下拉菜单，显示名称、说明、选中标记 | 从适配器确认的能力目录读取真实模型 ID；支持的平台提供手动选择，不支持的平台明确显示“自动”，不提供无效选项 |
| 清晰度、时长及其他参数 | 跟随当前模型展示，批量生成前汇总 | 只暴露已验证可传的参数，模型改变时重新校验，不静默忽略不兼容的选择 |

### 模型选择的硬性约束

1. 用户在我们的网站选定模型，提交请求时必须真正使用对应的模型标识和执行来源，并在任务记录中保存。
2. 国际版 Dreamina CLI 文档支持模型发现和模型参数，但需以安装版本的 schema、实际目录和账号权限验证；当前国内 CLI 接入不代表国际版已接通。
3. 目前 Pippit 创作 API 适配不能保证指定其内部模型/技能，因此显示“Pippit · 自动”。不得把提示词中的模型名称包装成已强制选择成功。
4. 平台没有提供的模型、技能、风格或报价能力标为不支持或未知。不能凭官网控件存在就声称 API 也能控制。
5. 提交前显示来源、账号别名、模型、参数、参考资产和待处理范围。有真实报价时显示报价；没有报价时明确未知，不能把未知显示为 0。
6. 账号额度不足时暂停受影响项，允许选择另一个来源并重新校验；更换后费用或能力发生变化必须呈现给用户，不自动扩大付费任务范围。

## 4. 可恢复任务与账号切换

### 4.1 任务粒度与状态

任务分为分析批次、角色/场景/道具设计、分镜设计、单张图片、单段视频、下载与导出等独立单元。每项至少记录：

- 本地任务 ID、项目 ID、任务类型和目标资产/分镜 ID。
- 输入版本、提示词、参考资产版本、生成参数快照。
- 平台、账号凭据引用、实际模型、第三方任务 ID及必要的恢复标识。
- 状态、尝试次数、时间、失败原因、已知报价/消耗及来源；未知费用单独表示。
- 结果的本地资产 ID、文件位置和校验结果。

建议状态：待执行、执行中、等待确认、等待权限/额度、结果未知、下载中、已完成、失败、已取消。远端返回成功但文件尚未保存时，不能标为本地成果已完成。

### 4.2 继续剩余任务

- “继续未完成”只选择待执行或用户确认可重试的任务。正在运行、结果未知和已完成项不自动重新提交。
- 额度不足时保留队列和已保存结果，提供“更换账号/API 后继续”。不要求用户重新导入剧本或创建新项目。
- 第三方任务仍在运行时，保留原账号及任务归属并查询原任务；换账号只影响尚未提交的任务。
- 请求超时或应用重启后先查原任务，避免重复提交和重复扣费。
- 下载失败仅重试下载；本地文件丢失与生成失败是不同问题，不自动付费重做。
- 若原账号失效，无法查询的远端任务标为结果未知；用户可明确选择重新生成，但必须说明可能已有远端任务产生费用。
- 更换模型导致参考素材或参数不兼容时，显示具体冲突，由用户修订或取消，不擅自丢弃参考图。
- 重启后从数据库恢复任务与进度，不能仅依赖网页内存或后台进程内存。

## 5. 统一资产存储与引用

- 本地资产库是项目的主要成果来源。文字设定、提示词、图片、视频和必要元数据在我们自己的存储中保存。
- 文件须实际下载并校验格式、可读取性和完整性；只有远端 URL、缩略图、第三方节点 ID 或素材 ID 不算保存完成。
- 资产使用稳定本地 ID，与平台账号无关。记录来源用于追溯，但不要求原账号有效才能读取本地文件。
- 向不同平台/账号使用素材时，按需上传同一份本地参考，保存“本地资产版本 → 平台/账号 → 远端素材标识”的映射。不同账号的远端标识不能直接混用。
- 资产修改产生版本；已提交任务保留输入快照，不因公共设定后来变化而改写历史。
- 项目、资产库、画布引用同一资产记录，避免三处状态各自不一致。画布不是唯一存储位置。
- 项目导出应含素材文件、设定、提示词、任务状态与引用清单；不含密钥、授权令牌。导入后无需原平台账号即可浏览已保存成果。
- 账号注销不会删除本地成果；本地磁盘损坏、用户删除、未完成下载则不在此保证内，需要项目备份与完整性提示。

## 6. 账号与平台适配边界

- 账号管理支持多个命名账号或 API 配置，凭据加密保存；页面与日志只显示别名和必要的非敏感状态。
- 每个适配器分别声明分析、图片、视频、上传参考、手动模型选择、报价、进度查询、下载与恢复能力，并标注已验证、未验证和不支持。
- 国内即梦、国际版 Dreamina、Pippit 是独立来源；授权、区域、画布 ID、素材 ID 和账号权益不能互相假定兼容。
- CLI 多账号并发隔离需通过实际版本的 profile/凭据隔离能力验证。未验证前，不通过频繁覆盖默认登录态模拟多账号并发。
- 服务端会员权限拒绝必须显示真实原因，不能绕过或自动付费升级。
- 断开账号连接和删除本地项目是不同操作。断开账号不会删除项目、资产或历史任务。

## 8. 开发顺序与交付标准

1. **任务与资产基础**：持久化任务、账号引用、输入快照、资产版本和文件校验；保留现有项目数据，不覆盖旧成果。
2. **分析增量与恢复**：拆分长剧本分析，完成部分即时显示；中断、重启、更换可用文本 API 后继续剩余项。
3. **生成队列与来源切换**：角色/场景/道具图片及片段视频按项执行，完成即回填，额度不足时换账号继续。
4. **网站选择器统一**：按截图交互提供风格、目标地区、比例，以及生成平台/账号/模型和实际支持参数；选择值影响真实请求并可追溯。
5. **国际版 Dreamina 适配**：在独立授权与账号权限允许后验证模型目录、参考上传、报价、单项生成、任务恢复、结果下载；通过后纳入相同队列。
6. **离线与跨来源验收**：用小规模授权任务验证切换、恢复和原账号断开后的项目可用性，再扩大任务规模。

每次交付在进度记录中写明改了什么、哪些路径通过验证、哪些仍受平台或账号限制。没有完成的项不能因为出现按钮、进度动画或官网跳转就标为完成。

## 9. 必须执行的验收场景

- 分析完成一部分后人为中断，刷新/重启仍显示已完成内容，切换另一可用 API 后只处理剩余项。
- 图片任务完成 5/10 项后模拟账号额度不足，选择另一已授权账号完成后 5 项；前 5 项不重做，所有结果在同一项目显示。
- 已提交视频在本地等待超时后，通过原任务 ID 恢复；不产生第二次生成提交。
- 远端任务成功但下载失败时，界面显示待保存，恢复网络后只补下载。
- 在生成前选择支持的模型、比例、清晰度，检查任务快照和适配器请求确实一致；不支持的选项不能提交。
- 选择风格和视频目标地区，重新打开项目后值仍在，生成输入中能追溯其生效方式。
- 更换来源后出现不兼容参数时，明确提示并要求修订，不静默采用其他模型或丢掉参考。
- 原账号全部断开后，已下载资产仍能预览、编辑、导出；向新来源生成时能从本地文件重新上传参考。
- 一个来源结果到达较晚时，不覆盖用户已经确认的新版本；保留结果供选择。
- 项目导出与重新导入能恢复已保存素材及引用，不携带任何平台凭据。
