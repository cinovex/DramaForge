# DramaForge 进度记录

## 2026-10-26：Pippit 会话与图片/视频参考入口

- AI 编剧和重制转绘改为网站内的会话界面：用户需求、Pippit 回复、实际工具调用、追问、结果预览，以及底部持续回复输入区。
- 支持选择或拖入多张图片/多个视频，显示本地缩略图、移除和逐文件上传进度；原会话回复可携带新的参考素材，发送前保留积分确认。
- 接入现有上传接口的真实限制：PNG/JPG/WEBP/MP4/MOV/WEBM，每个最多 200 MB，每次最多 32 项。暂不声称支持音频或任意文件。
- 本地缓存会话接口可读取已保存回复，串联同一线程中的已保存轮次；保留同一消息 ID 的不同内容片段，避免漏掉步骤。运行中自动查询，结束或需要回复后停止。
- 工具记录显示“已请求”；接口未返回独立完成状态时，不伪造“技能已加载/执行成功”。模型和技能仍由 Pippit 自动选择。
- 使用已有会话核实 12 条消息、12 项工具调用和生成结果；未重新提交付费创作。新附件上传并生成的完整流程仍待授权实测。

## 2026-10-26：分析任务逐项保存与暂停续做

- 初次分析改为按明确分集标题分段，超长分集继续拆成最多约 6000 字的小段；每段校验后与检查点同事务保存，保留原文，不删除已有资产和媒体。
- 增量合并同名角色、场景、道具，分镜按本地集序追加；未标分集的文本保留一集，不由分块数量虚构集数。
- 深化分析的角色/场景设计及每个分镜设计完成后立即落库；缓存指纹不再包含自身生成的字段，避免逐项保存后缓存自动失效。兼容原有未落库缓存。
- 增加持久化分析任务状态、尝试次数、来源平台/模型/配置版本记录，不记录密钥；执行期间固定文本配置，暂停后继续才读取新配置。
- 新增暂停接口和页面按钮、继续未完成项、已保存内容列表、任务来源；更换配置按钮直达文本模型设置。
- 请求超时/服务重启不会自动重新调用付费文本接口，保留已完成项，对未确认请求提示可能已产生费用。
- 范围说明：本阶段是文本分析的续做基础，不等于多账号管理、媒体统一队列、国际 Dreamina 生成适配已完成。仍需授权的付费端到端验收。
