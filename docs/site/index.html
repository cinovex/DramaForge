ONE CONNECTED WORKFLOW

创作不止于一段提示词。

从故事结构到生成结果，保留每一步可以继续编辑的内容。

01 / 理清故事

剧本分析与制作资产库

导入或粘贴剧本，整理分集、角色、场景、道具与分镜。查看设计说明和提示词，单张或批量生成制作参考图。

02 / 组织镜头

剧集、分镜与节点画布

按集查看片段，编辑并保存提示词，在资产库、脚本和预览之间继续制作。节点画布支持自由组织创作内容。

03 / 连接生成

模型选择与 Pippit 集成

使用已配置的图片、视频服务，或选择 Pippit 提交创作。记录任务状态，将返回的素材保存到对应项目。

GET STARTED

在你的电脑上开始。

需要 Git、Node.js、Bun 与 Python 3.11。第三方生成服务需自行配置，可能收费。

四步启动工作台

  1. 获取代码并安装依赖
  2. 构建创作界面
  3. 启动本地服务
  4. 配置模型，导入剧本
查看完整 README ↗
01获取代码与安装依赖
git clone https://github.com/cinovex/DramaForge.git
cd DramaForge
bun install
cd backend
python -m pip install -r requirements.txt
cd ../frontend
npm install

建议先为 Python 创建虚拟环境。后续命令从仓库根目录开始。

02构建创作界面
cd apps/web
bun run build

修改创作界面后，需要重新构建，再刷新网站。

03分别在三个终端启动服务

以下为 Windows PowerShell 命令。每个终端从仓库根目录开始。

画布服务 · 3001

$env:TOONFLOW_PORT="3001"
$env:TOONFLOW_DATA_DIR="$PWD/storage/canvasData"
bun run --filter '@toonflow/server' dev

生成与项目服务 · 8000

cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000

网站入口 · 3000

cd frontend
npm run dev

启动后，在同一台电脑打开 http://localhost:3000。

04完成第一次创作
  1. 在设置中填写模型服务地址、模型名称和 API 密钥。
  2. 上传 TXT 或粘贴剧本，开始分析并查看进度。
  3. 在制作资产库检查设定，生成角色、场景和道具参考图。
  4. 进入剧集，编辑片段提示词、选择模型，再提交生成。

Pippit 需额外配置自己的访问密钥。内部模型由 Pippit 自动安排；需要补充信息时，查看任务回复。密钥只保存在本地配置，不要提交到 GitHub。
