# 参考图与跨集一致性

DramaForge 把一个项目中的角色主图、场景主图视为全剧固定资产。新镜头按出场角色和场景自动绑定；即使手动添加参考图，也会补齐该镜头出场角色和场景。名称不匹配、缺图、原图地址失效时会在提交付费视频任务前报出具体资产。Agnes 视频接口不能同时提交 `images` 和 `first_frame`：自动模式在关键帧有可访问地址时优先使用关键帧，否则使用角色/场景参考图；明确手动选择了参考图时则尊重该选择。关键帧生成时以同一组角色/场景图为输入。四视图与表情宫格不会自动传给视频模型，避免把多格拼图误当成单一画面；可在“图片参考”里按需手动选择，优先选择单视角图。

重新生成角色或场景主参考只生成候选图片，不会改变已经启用的全剧主图。确认新图后，在资产“参考图片”中点击“启用此版本”。每个视频任务保存实际使用的资产 ID、图片路径、模型、画幅及提示词，旧镜头可按提交时的版本追溯。视频完成后进入“待检查”，在导演面板对照实际参考图确认或标记重做。视觉一致性仍需人工确认；系统不会把文字或像素相似度当作可靠的人脸识别结果。

Agnes 图片接口请求 `extra_body.response_format=url` 时，其返回的原图 URL 会记录在 `image_sources`。如果图片服务只返回 Base64，本地图仍可预览，但 Agnes 视频需要公网可访问的 HTTPS 图片 URL。可为本项目配置 S3 兼容对象存储（包括 R2）：

```
DRAMAFORGE_MEDIA_BUCKET=your-bucket
DRAMAFORGE_MEDIA_ENDPOINT=https://your-s3-endpoint
DRAMAFORGE_MEDIA_ACCESS_KEY=...
DRAMAFORGE_MEDIA_SECRET_KEY=...
DRAMAFORGE_MEDIA_PUBLIC_BASE=https://your-public-image-domain
```

公网域名须能无登录访问该桶中的 `dramaforge/images/...` 对象，且保持长期有效。配置后重启后端，新图会上传到该桶；旧图可调用 `POST /api/projects/{项目ID}/references/publish` 迁移，包括过去已有提供商地址的图片。没有配置时，系统使用图片提供商返回的原图 URL；缺失地址时会在生成前阻止视频提交。不要把密钥写入项目源码或提交到版本库。

成片导出会先确认所有目标镜头完成、文件存在且达到计划时长，然后把各段裁剪到计划秒数、统一画幅/帧率/音轨后拼接，最后核对总时长。比例不合的素材会居中裁切以避免黑边，重要主体靠近画面边缘时请先检查镜头构图。旧视频没有生成清单，检查面板会显示“没有逐张参考图记录”；新视频才会自动保存清单。
