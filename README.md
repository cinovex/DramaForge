# DramaForge

面向 AI 短剧制作的本地创作工作台。在 Toonflow 开源界面与节点画布基础上，融合 DramaForge 的剧本分析和素材生成流程，并探索 Pippit 海外 API 接入。

> 当前为开发预览版。部分入口已搭建，但不代表完整业务链路已验证。需要自行准备模型服务账号和 API 密钥，第三方生成可能收费。

## 架构

- `apps/web`：Vue 3、Element Plus、节点画布与设置界面。
- `apps/server`：Bun/TypeScript，工作区、画布和工具服务，开发端口 3001。
- `backend`：Python/FastAPI，剧本分析、生成任务和 Pippit 适配，端口 8000。
- `frontend`：Next.js 入口与代理，端口 3000。
- `packages`：共享组件、节点、工具及供应商适配。

## 本地运行

准备 Node.js、Bun 和 Python 3.11。以下操作分别在对应终端运行。

1. 仓库根目录安装工作区依赖并构建界面：

```powershell
bun install
cd apps/web
bun run build
```

2. 根目录启动画布服务：

```powershell
$env:TOONFLOW_PORT="3001"
$env:TOONFLOW_DATA_DIR="$PWD/storage/canvasData"
bun run --filter '@toonflow/server' dev
```

3. 启动 Python 服务（建议先创建虚拟环境）：

```powershell
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

4. 启动网站入口：

```powershell
cd frontend
npm install
npm run dev
```

访问 http://localhost:3000 。若首页没有跳转，可进入 http://localhost:3000/canvasApp/index.html#/home 。修改 `apps/web` 后需重新构建。仓库中的 Windows 启动脚本仍包含本机路径，使用前需要调整。

## 使用方法

1. 在首页全局设置中配置文本、图片、视频模型的服务地址和密钥。
2. 在短剧工作室上传 TXT 或粘贴剧本，选择画幅后开始分析。
3. 打开项目画布，检查人物、场景及分镜，再执行需要的生成任务。
4. 重制入口可上传参考视频并描述改编要求。可刷新任务状态、回复同一会话、保存生成素材到资产库。不能视为完整官网功能替代。

## Pippit 配置与限制

项目使用官方 `pippit-skill`。可在服务进程中设置 `PIPPIT_ACCESS_KEY`；也支持技能提供的本地密钥缓存。不要将真实密钥提交到仓库。

现有接入提交自然语言需求和参考素材，由 Pippit 自动安排技能与模型。时长、画幅、分辨率在一次单镜头测试中已转换为生成参数，但最终输出和其他任务仍需逐项验证。多账号积分不能直接合并，后续计划通过任务分配和各账号独立上传素材实现复用。

## 2026-10-22 更新

- 将创作、技能、资产库拆分为同一工作室下的不同内容区，资产库不再只是滚动到首页项目列表，技能不再只是首页弹出菜单。
- 资产库读取真实项目的角色、场景、道具、关键帧和视频，支持分类、媒体筛选、搜索、排序、列表/网格、复制提示词及进入原项目画布。音频筛选入口已提供，但当前没有音频导入或生成链路。
- 默认暗色主题与中性灰强调色，移除首页渐变、星光和连接线背景；已有用户仍可在全局设置中切换主题。
- 创作页可选择工作室智能体或 Pippit 海外创作；后者直接通过 API 提交文本与图片/视频附件，由 Pippit 自动编排模型和技能。
- Pippit 创作任务保存到本地数据库，显示任务历史、进度文字、实际回复和结果链接，支持同一会话继续修改。会话结束不代表一定生成成功，需检查实际回复。
- 保存 Pippit 生成素材时，重新查询任务，只接受助手生成素材，下载后加入项目与资产库；重复保存返回原项目，并读取真实视频时长和画幅。移除画布中固定显示的 TF-Router 充值入口。此功能未把 Pippit 反解结果自动推断成角色/场景/道具。
- 网站、独立画布服务与移动服务的版本信息不再依赖本机 `.hutch` 桌面开发文件。
- 实际接口检查：现有 OpenAI、Agnes 图片/视频、Pippit 配置连通；不公开密钥。红球测试已生成并保存，重复导入不新增项目；真人重制任务因 Pippit 积分不足结束，无成片可导入。

尚未完成：多账号密钥管理与素材映射、任务调度、完整反解资产结构化回收、Pippit 强制模型/技能选择、积分与单步计费查询、全局音频上传、一键安装与桌面分发。未验证或没有开放的接口不以网页同名按钮代替实现。
